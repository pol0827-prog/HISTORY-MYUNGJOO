# 시대를 헤쳐가는 지혜를 배우는 즐거운 역사수업

구글 설문지·시트·Apps Script로 만든 두 웹앱(수업 도입용 연상 단어, 수업 마무리용 배움 일기)을
**Firebase + GitHub + Vercel** 로 하나의 앱으로 합친 버전입니다.

- **🚪 오늘 배움 시작**: 학생이 연상 단어 2개 제출 → 단어 구름, 빈도 Top 5 그래프, 최다 키워드 Top 3
- **🏁 오늘 배움 마무리**: 학생이 별명 + 배움 일기 제출 → 키워드 Top 5, 일기 목록, 선생님 추천, AI 추천, 별명 명작
- **🎤 발표**: 학생·모둠이 사진(4장), 링크(3개), 발표 내용을 올리면 발표용 슬라이드 화면으로 자동 구성 (자기 휴대폰에서 다시 고치기 가능, 교사도 고치기·순서 바꾸기·숨기기)
- 반마다 학생 제출 QR이 달라서 반별로 기록이 따로 쌓입니다
- 학생이 제출하면 새로고침 없이 수업 화면에 바로 반영됩니다

## 링크 4개 (로그인 없이 누구나 열림)

| 링크 | 누가 | 하는 일 |
|---|---|---|
| `https://(주소)/#class` | 교사·학생 함께 | 수업 화면. 교실 화면에 띄우거나 학생에게 줘도 됨 |
| `https://(주소)/#intro` | 학생 | 오늘 배움 시작 제출 (학번, 이름, 단어 2개) |
| `https://(주소)/#write` | 학생 | 오늘 배움 마무리 제출 (학번, 이름, 별명, 일기) |
| `https://(주소)/#teacher` | 교사 | 선생님 비밀번호로 들어가는 교사 관리 모드 |

수업 화면의 QR 코드는 지금 단계(배움 시작/마무리)에 맞는 학생 제출 링크로 자동으로 바뀝니다.
배움 마무리 수업 화면에는 학생 이름이 나오지 않고(별명·학번만), 이름은 교사 관리 모드에서만 보입니다.

## 1. Firebase 준비 (10분)

1. https://console.firebase.google.com → **history-myungjoo** 프로젝트 열기
2. **빌드 > Firestore Database > 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**
3. Firestore **규칙** 탭 → 이 폴더의 **`firestore.rules`** 내용을 전부 붙여넣고 **게시**
4. **빌드 > Authentication > 시작하기 > 로그인 방법 > 익명(Anonymous)** 을 **사용 설정**
   (교사 관리 모드 비밀번호 확인에 씁니다. 학생은 로그인하지 않아요)
5. 웹 앱 설정값은 이미 코드에 들어 있어요 (프로젝트 `history-myungjoo`)

### 교사 관리 모드 비밀번호 바꾸기

비밀번호는 **`firestore.rules` 안에만** 있습니다(`TEACHER_PIN`).
공개 저장소에는 비밀번호를 넣지 말고, Firebase 콘솔의 규칙 탭에서 '여기에-비밀번호' 자리에 실제 비밀번호를 넣어 **게시**하면 끝이고, 앱 코드는 고칠 필요가 없어요.
화면 코드에는 비밀번호가 들어 있지 않아서 학생이 페이지 소스를 봐도 알 수 없습니다.
다만 숫자 4자리는 마음먹고 추측하면 뚫릴 수 있으니, 가능하면 더 긴 비밀번호로 바꾸는 걸 추천해요.

## 2. GitHub에 올리기

1. https://github.com/new 에서 새 저장소 만들기 (예: `history-class`)
   → **Private(비공개)** 로 만드세요. `firestore.rules` 에 비밀번호가 들어 있어요.
2. **uploading an existing file** 을 눌러 이 폴더의 파일을 모두 끌어다 놓고 **Commit**
   (`node_modules`, `dist`, `.env` 는 올리지 않습니다)

## 3. Vercel 배포

1. https://vercel.com 에 GitHub 계정으로 로그인 → **Add New > Project** → 방금 저장소 **Import**
2. Framework는 **Vite** 로 자동 선택됩니다
3. **Environment Variables** 에 **`GEMINI_API_KEY` 하나만** 추가
   - https://aistudio.google.com/apikey 에서 **Create API key** 로 받은 키
   - 이름 앞에 `VITE_` 를 붙이지 마세요. 키는 서버에서만 쓰이고 학생 화면에는 보내지지 않습니다
   - Firebase 설정값(history-myungjoo)은 이미 코드(`src/firebase.js`)에 들어 있어서 넣지 않아도 돼요
4. **Deploy** → 주소가 나오면 완료 (예: `https://history-class.vercel.app`)
5. Firebase 콘솔 **Authentication > 설정 > 승인된 도메인** 에 Vercel 주소(예: `history-class.vercel.app`)를 추가

환경 변수를 나중에 추가하거나 바꿨다면 **Deployments > Redeploy** 를 한 번 눌러야 적용됩니다.
GitHub에 파일을 고쳐 올리면 Vercel이 자동으로 다시 배포합니다.

## 교사 관리 모드에서 할 수 있는 일

- **지금 화면** 전환: 🚪 오늘 배움 시작 / 🏁 오늘 배움 마무리 → 교실 수업 화면이 바로 따라 바뀜
- 제출 기록 검색, 숨기기·수정·삭제, 기록 전체 비우기(새 수업 시작)
- 선생님 추천 일기, 별명 명작 추천 3개 고르기
- **🤖 AI로 다시 고르기**: Gemini가 일기를 읽고 1편과 고른 이유를 수업 화면에 표시
  (키가 없거나 실패하면 키워드 방식으로 자동 선정)
- **⚙️ 화면 설정**: 과목명, 제목, 부제, 안내 문구, 시작·마무리 명언, AI 추천 기준. 세계사·과학·국어 예시 제공
- **🖨️ 자료 인쇄**
  - 🖼️ 수업 화면 게시용: 학생 글 **전부**를 A4 또는 B4(257×364mm) 한 장에 맞춰 인쇄 (세로/가로)
  - 배움 시작: 연상 단어 전체, 연상 단어 정리 한 장
  - 배움 마무리: 학생 일기 전체, 오늘의 추천 모음, 수업 정리 한 장, 학생별 카드
  - 인쇄 창에서 배율은 "기본값/실제 크기"로 두세요. PDF로 저장도 됩니다
- 오른쪽 위 현재 시각, ☀️ 밝게 / 🌙 어둡게 전환

## 다른 과목 선생님이 쓰려면

Firebase 프로젝트를 새로 하나 만들고 같은 코드를 배포하면 데이터가 서로 섞이지 않아요.
과목에 맞는 문구는 교사 관리 모드 > 화면 설정에서 바꾸면 됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `src/` | 앱 화면과 동작 |
| `src/presets.js` | 세계사·과학·국어 화면 문구 예시 |
| `api/ai-pick.js` | Gemini AI 추천 (Vercel 서버 함수) |
| `firestore.rules` | Firebase 보안 규칙 (교사 비밀번호 포함) |
| `미리보기-데모.html` | 더블클릭으로 열리는 예시 데이터 데모 (저장 안 됨) |

`index.html` 은 더블클릭으로는 열리지 않아요. 배포 주소로 열거나, 이 폴더에서 `npm install` → `npm run dev` 후
`http://localhost:5173` 을 여세요.

## 데이터 구조 (Firestore)

- `entries/{ID}`: 배움 마무리 일기 `sid`(학번), `nick`(별명), `body`(일기), `hidden`, `createdAt`
- `entryNames/{같은 ID}`: 학생 이름 `sid`, `name` (교사만 읽기)
- `intro/{ID}`: 배움 시작 `sid`, `name`, `w1`, `w2`, `hidden`, `createdAt` (같은 학번은 최근 제출만 화면에 표시)
- `settings/config` 화면 문구, `settings/picks` 추천, `settings/ai` AI 추천, `settings/state` 지금 화면
- `presents/{반~ID}`: 발표 자료 제목·발표자·내용·링크·작은 사진, `presentPhotos/{같은 ID}`: 발표 사진
- `sessions/{기기}`: 비밀번호로 들어온 교사 기기 기록


## 2026-10 수정 내용

- **🧑‍🏫 칠판 판서**(새 화면): 교사 관리 모드 → 지금 화면 → 칠판 판서. 대단원명·소단원명·학습 주제·성취기준과 오늘의 강의 내용을 적고 [칠판에 쓰기]를 누르면 수업 화면이 초록 칠판에 분필로 쓴 것처럼 바뀝니다. [칠판 가로 전체 화면]을 누르면 가로로 꽉 차게 보여요(휴대폰은 가로로 고정, 안 되면 칠판을 돌려서 보여 줌).
  - 강의 내용 쓰는 법: `# 소제목`(노란 분필) · `- 내용`(글머리표) · `! 중요`(분홍 분필) · `**강조**` · `->`(화살표) · 빈 줄(칸 띄우기). 내용이 많으면 글씨가 자동으로 줄고 두 칸으로 나뉩니다.
  - 저장 위치: `settings/board` (규칙 변경 없음)
- **나의 별명**은 이제 **오늘 배움 시작**에서 받습니다(배움 마무리에서는 뺌). 별명 명작 추천도 배움 시작 화면으로 옮겼고, 배움 마무리 일기에는 같은 학번의 별명이 자동으로 붙어 보여요.
  - ⚠️ `firestore.rules`를 Firebase 콘솔에 **다시 게시**해야 학생들이 별명을 낼 수 있어요.
- 교사 관리 모드: '수업 들어가는 반'을 '수업 화면 사진' 위로, '자료 인쇄'를 '수업 링크' 바로 위로 옮김. 인쇄의 '수업 정리 한 장'·'학생별 카드' 삭제.
- `public/map.jpg`: 2차 세계 대전 세계지도를 기본 그림으로 넣음
